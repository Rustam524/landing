# ALGORITM — лендинг цифрового агентства

Одностраничный сайт-лендинг на чистом HTML/CSS/JS (без сборки и зависимостей).

## Структура

```
index.html            — разметка страницы
assets/css/style.css  — стили (чёрно-красная цветовая схема)
assets/js/script.js   — прелоадер, меню, плавный скролл, форма заявки
```

## Как открыть

Просто откройте `index.html` в браузере — либо запустите локальный сервер:

```bash
python3 -m http.server 8000
```

и перейдите на `http://localhost:8000`.

## Деплой

Файлы статические — подойдёт любой бесплатный хостинг: GitHub Pages, Netlify, Vercel, Cloudflare Pages.
