# ALGORITM — рабочее пространство

Внутренняя система управления сотрудниками, проектами, задачами и
отчётностью маркетингового агентства **ALGORITM**. Реализует Этапы 1–2 из
технического задания: авторизация и роли, сотрудники, клиенты, проекты,
задачи со статусами, комментарии.

Стек: **Next.js (App Router) + TypeScript + Tailwind CSS + Supabase**
(Postgres, Auth, Row Level Security).

## Быстрый старт

```bash
npm install
cp .env.example .env.local   # заполнить ключами Supabase — см. SETUP.md
npm run dev
```

Подробная инструкция по созданию и подключению проекта Supabase —
в [`SETUP.md`](./SETUP.md).

## Структура

- `src/app/(auth)/` — вход, смена пароля, восстановление пароля.
- `src/app/(app)/` — авторизованная часть: главная, сотрудники, клиенты,
  проекты, задачи, настройки.
- `src/lib/supabase/` — клиенты Supabase (браузер / сервер / service role).
- `src/lib/i18n/` — локализация (русский и казахский).
- `supabase/migrations/` — схема базы данных, триггеры и политики RLS.

## Роли

Директор · Руководитель проектов · SMM-специалист · Таргетолог ·
Мобилограф — права описаны в `supabase/migrations/0003_rls.sql` и
`src/lib/auth/permissions.ts`.
