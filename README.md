# ALGORITM — как работать

Чтобы больше не путаться. Два разных дела, два разных места.

## Боевой сайт

Адрес: https://algoritm.top/  
Это **одна страница**: тарифы, WhatsApp, контакты.

Код лежит в ветке **`main`**.

Живой сайт сейчас в Netlify (проект `algoritm-kz`). Его обновляют **вручную**, не из GitHub.

**Правило:** на algoritm.top выкладывать только эту одну страницу. Черновик туда не тащить.

## Черновик

Многостраничник: услуги, обучение, блог, о нас, кейсы.

Ветка: **`cursor/multipage-homepage-draft-f437`**

Это тест. Люди на algoritm.top его видеть не должны. В Google его не открывать.

## Ещё два отдельных проекта (не этот репозиторий)

- Платформа сотрудников — Netlify `algoritm-platform`
- Курс SMM — Netlify `algoritm-kurs`

Их отсюда не трогать.

## Если нужно выложить боевой

Берёте файлы из `main` (index.html и папка assets) и заливайте в Netlify `algoritm-kz`.  
Папку черновика туда не перетаскивать.
