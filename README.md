# ALGORITM

**Боевой сайт:** https://algoritm.top/  
Это **одна страница** (тарифы, WhatsApp, контакты).

## Чтобы не путаться

| | Боевой | Черновик |
|---|---|---|
| Что это | одностраничник | многостраничник (услуги, блог, «о нас») |
| Ветка | `main` | `cursor/multipage-homepage-draft-f437` |
| Netlify | Production = `main` | не назначать Production |
| Google | только эта страница | не индексировать как сайт агентства |

Черновик собирается отдельно. Его нельзя публиковать на algoritm.top.

## Файлы боевого сайта

- `index.html` — вся страница
- `assets/css/style.css` — стили
- `assets/js/script.js`, `assets/js/i18n.js` — меню, язык RU/KZ, форма

Сборки нет. Netlify просто отдаёт файлы как есть.
